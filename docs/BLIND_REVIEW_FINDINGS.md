# Blind External Review — V6 Use

The external review was performed without being told that the repository represented V6. Its observations are treated as candidate adversarial findings, not as an authority on V6 semantics.

The useful methodology is to attack observable semantics, mathematical correctness, approximation-vs-exactness claims, tolerance scaling, invalid domains, algebraic rank, topology invariants, and public-vs-internal semantic consistency.

V5 behavior is a compatibility reference only where V6 explicitly requires parity. A V5-only semantic difference is not a V6 defect by itself.

Confirmed V6 findings must be promoted to regression contracts before fixes. Unconfirmed findings remain hypotheses.

The first V6 independent-oracle suite now verifies analytically derived primitive bounds, canonical box topology and Euler invariant, affine translation behavior, translation composition, and full-turn rotation identity.
